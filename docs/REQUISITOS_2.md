# <u>CONDICIONES GENERALES</u>

- El proyecto debe ser desarrollado en el lenguaje de programación C + + y CMake. O con el lenguaje de programación Kotlin y Maven/Gradle.
- El uso de OpenGL (vía C + + o LWJGL) es obligatorio. No se permite el uso de motores gráficos preexistentes (ej. Unity, Unreal, Godot)."
- El proyecto puede ser entregado en parejas, o en grupos de 3 integrantes.
- La fecha de entrega queda pautada para el día **23 de octubre de 2026** hasta las 11:59 PM (GMT-4).
- Todos los proyectos tendrán una defensa asociada, donde los desarrolladores deberán exponer su solución y explicar sus decisiones de diseño. Se recomienda llevar una laptop con el proyecto funcionado.
- El código debe ser entregado en un zip. con el formato siguiente:

  **PROY3_CEDULA1_CEDULA2.zip**

  a [bryansilva.dev@gmail.com](mailto:bryansilva.dev@gmail.com), con el asunto replicando el nombre del archivo .zip en el correo.
